# PC Time Tracker

Лёгкий десктопный трекер времени для Windows. Считает, сколько вы проводите за компьютером, с автопаузой при бездействии, настраиваемой дневной целью и историей за 7 дней.

![Python](https://img.shields.io/badge/python-3.10+-blue)
![Platform](https://img.shields.io/badge/platform-Windows-lightgrey)
![License](https://img.shields.io/badge/license-MIT-green)

## Возможности

- 🕒 Большой таймер текущей сессии + итог за день
- ⏸ Кнопки **Старт / Пауза / Сброс**
- 😴 **Автопауза** при бездействии — порог настраивается (10…3600 сек)
- 🎯 Настраиваемая **дневная цель** (1–24 ч) с прогресс-баром
- 📊 **История за 7 дней** с прогресс-барами по каждому дню
- 🪟 Режим «Поверх всех окон»
- 💾 Автосохранение каждые 10 секунд и при закрытии — сессии переживают перезагрузку
- 🎨 Тёмная тема, шрифты Consolas / Segoe UI
- 🌐 **10 языков интерфейса** — English (по умолчанию), Русский, 中文, Español, Français, Deutsch, Português, 日本語, 한국어, العربية

## Установка и запуск

Требуется **Python 3.10+** с модулем `tkinter` (входит в стандартную поставку на Windows).

```bash
python src/pc_time_tracker.py
```

Также можно просто дважды кликнуть по файлу, если `.py` ассоциирован с Python.

## Где хранятся данные

Все настройки и история хранятся в одном JSON-файле:

```
%APPDATA%\PCTimeTracker\data.json
```
